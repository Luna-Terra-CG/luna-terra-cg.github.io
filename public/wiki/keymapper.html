wiki/The Key Mapper tutorial

Note: This guide is meant for users of blackberry and physical keyboard devices

This page is meant to give you a good enough understanding of how to use the Key Mapper app to make your own key maps without help.

Please note that this is not at all affiliated with the Key Mapper project.

If you have issues with this guide please contact me directly using one of the contact points listed on my index page.

If you don't already have it installed you can get keymapper from Google Play Store, F-Droid and Github.

Now, with that out of the way, let's get started!

Once you have given Key Mapper the required permissions the home page will look like this

For the first example, we'll launch the messages app when you press the Speed (left shift) and M keys at the same time

So press the floating '+ New key map' button to get started

Now to map your keys press the red 'Tap to record trigger' button, and press M and Speed at the same time

If only one key registered you can press the map button again, and press the key that didn't register.

Note: Pressing the record button again only adds new keys, it doesn't remove ones already in the list.

Now set the button near the bottom to 'Press together' to make sure it always registers on the first try

Note: if you want to change the ordering of your keys in the list, drag the two lines on the left to move a key

With all that set up it should look like this

Great! Now we can move on to making this key map do something.

This is where the 'Actions' tab comes in, here you can set what you key bind does

So move over to the actions tab and press the 'Add actions' button

What you need is the 'Launch app' action, you can ignore those other ones for now

Note: If your on LineageOS or a rom closer to stock android, you can ignore the warning pop up

Now pick the messages app

Your done setting up this binding for now, so you can press the 'Done' button

Congratulations you've made your first keybind!! Now try it out!
