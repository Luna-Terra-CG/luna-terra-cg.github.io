Installing SFOS 1

Unlock the bootloader and flash the final factory image from: https://developers.google.com/android/images#hammerhead

Boot into the bootloader and flash the twrp recovery file fastboot flash recovery twrp-3.7.0_9-0-hammerhead.img

Enter recovery mode thru the bootloader menu

Format data in the Wipe menu

Sideload the cm-11 zip in Advanced/ADB Sideload, then WITHOUT REBOOTING do the same with the sailfishos zip.

Reboot the phone

Yup that it. Looks so short compared to the other one, doesn't it?

Installing every other version

Note: This whole section is based on https://talk.maemo.org/showpost.php?p=1574832&postcount=1220 but with some issues fixed, all credit goes to edp17!!!

This assumes you are not rooted, have an unlocked bootloader and are running the final android 6.0.1 factory image from https://developers.google.com/android/images#hammerhead

Boot the .img file from CF-Auto-Root.zip with fastboot boot CF-Auto-Root-hammerhead-hammerhead-nexus5.img

It will reboot several times, do not turn it off during this.

Once that finishes flash the TWRP multirom file.

Sideload kernel_kexec_hammerhead_601.zip then multirom-20160207-v33-hammerhead.zip

Reboot into the stock rom after sideloading the second zip file

Note: You can press Do Not Install when rebooting since it's already rooted

Boot into recovery.

Uncheck the cache option in the mount menu

Disable and re enable MTP

Copy cm-12.1-20160704-UNOFFICIAL-hammerhead-nocheck.zip and your Saifish OS zip to the device via MTP

Unplug the USB cable

Go into Advanced, MultiROM, Settings, Configure autoboot

Set the radio buttons at the top to Disabled

Go into Advanced, MultiROM, Add ROM, SailfishOS, Next

Set the CyanogenMod ZIP file to cm-12.1-20160704-UNOFFICIAL-hammerhead-nocheck.zip

And set the Rootfs ZIP file to your Saifish OS zip file

Note: The flashing process can take over 10 minutes so you should plug in power

Reboot once it finishes, if you get a prompt to install root, press Do Not Install

Press the sailfish install twice to boot it

BOOTING INTO THE STOCK OS AT ALL WILL BRICK YOUR SAILFISH INSTALLATION

It may reboot after getting to the setup screen, if it does just boot sailfish again

Note: Pressing at the bottom of the screen when prompted in connect to wifi will let you skip logging into a Jolla account

If you want to try a different sailfish zip, format data in recovery.

Sideload kernel_kexec_hammerhead_601.zip then multirom-20160207-v33-hammerhead.zip

Fully poweroff

Then redo the block of flashing steps directly above

Fix bootloop after reflashing the factory image

Erase the boot, cache, recovery, system & userdata partitions with the fastboot erase command.

Then flash the images inside the image-hammerhead zip in this order: boot, recovery, cache, system. Don't flash userdata.img.
